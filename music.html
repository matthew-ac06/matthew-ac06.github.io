[IN PROGRESS] Slime Game Project - Title Theme
This is the title theme for the WIP Slime Game Project I'm creating with a friend. I wanted to create something that felt intriguing and futuristic, and I had just finished playing Tunic at the time, so I felt very inspired to write a synth-y, DNB type of track.
[IN PROGRESS] Slime Game Project - Chaotic Theme
This is the first track I finished for the WIP Slime Game Project I'm creating with a friend. He needed a weird and frantic song for the chaotic levels, so I tried to recreate the feel of some of Splatoon's stranger songs. I also took inspiration from Neon White's OST for a more energetic vibe.
Aw Sap! - Main Theme
This was a short track I produced in 48hrs for my group's submission to the IGDA DC's District Jam #7. Our game was about a squirrel traversing a giant tree, so I looked to the "Big Tree"-type Mariokart tracks like Wild Woods and Acorn Heights for inspiration. Additonally, this was my first time challenging myself to use an odd time signature of 5/4.'
King Fisher - Crazy Fish
This was my contribution to the game developed by GMU GADIG in Spring 2026. Since the game is about fishing, the prompt for myself and other composers was to write a bluegrass-style, party game track. For this piece, I listened to a lot of my dad's bluegrass collection, as well as bluegrass-style tracks from party games like Mariokart.
King Fisher - Psycho Fish
This was a collaborative project created by myself and a friend for the game developed by GMU GADIG in Spring 2026. In addition to the bluegrass track, composers for GADIG Spring 2026 were asked to produce a 60 second "1 minute left!" track, like the "Now or Never" tracks from the Splatoon series, but in a DNB genre instead of bluegrass. I challenged myself to sample my own bluegrass theme and reimagine it as a DNB track, and it became one of the most interesting projects for me!
Deadshot - Desert Battle Theme
This was a collaborative project created by myself and a friend for the game developed by GMU GADIG in Fall 2025. This serves as a battle theme for the desert area of the game, and since the game is very inspired by classic spaghetti westerns, I listened to a lot of classics, like the obvious inspiration of The Good, the Bad, and the Ugly. However, I also took inspiration from games like Red Dead Redemption 2 and Undertale: Yellow.
Palm Breeze Zone
This was my final assignment for my first game music class. I took heavy inspiration from classic Sonic games, even using the Sonic CD soundfont for my instruments, since this was supposed to serve as the theme for a first-level type of Sonic stage.
